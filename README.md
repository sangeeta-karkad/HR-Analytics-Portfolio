# IBM HR Employee Attrition Analytics Dashboard (MS Excel) 📊

### Project Overview
Analyzed the IBM HR Analytics dataset (1,470 employee records) in MS Excel to identify the key drivers behind employee turnover and support data-driven HR retention strategies.

### Tools & Excel Features Used
* **Pivot Tables & Charts:** Visualized attrition trends across departments and overtime status.
* **Interactive Slicers:** Added dynamic filter buttons for **Department** and **Gender** to analyze workforce segments in real time.
* **VLOOKUP Search Tool:** Built an instant Employee ID lookup box to retrieve employee department records quickly.

### Key HR Business Insights
* **Overall Attrition Rate:** 16% (237 out of 1,470 employees left the organization).
* **Department Impact:** R&D and Sales departments experienced the highest turnover numbers.
* **Overtime Factor:** Employees working frequent overtime showed a significantly higher attrition rate, highlighting the need for workload balancing.
